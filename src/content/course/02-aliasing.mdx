## Сначала — два вращения

В прошлом уроке мы записывали горизонтальную координату точки на окружности. Теперь возьмём **два косинуса с амплитудой 1 и начальной фазой 0**: 1 kHz и 5 kHz. Оба будем измерять с частотой **Fs = 6 kS/s**.

За время между двумя отсчётами:

- точка 1 kHz проходит **60°**;
- точка 5 kHz проходит **300°**, почти полный оборот.

Обе вращаются в одном направлении. После первого шага одна оказывается сверху справа, другая — снизу справа. **Их положения разные, но горизонтальная координата одна: 0.5.** Именно её мы записываем.

<AliasingDemo />

При включённом «Только моменты измерения» передвигай ползунок от 0 до 6. В каждом шаге значения совпадают. Число пройденных градусов показывает, что быстрая точка действительно делает больше оборотов.

Теперь отключи эту галочку и поставь ползунок на **0.50**. Его шкала измеряется в интервалах между отсчётами: это $0.5T_s$, середина между отсчётами 0 и 1, а не 0.5 секунды. Значения станут примерно **+0.866 и −0.866**. Сигналы различаются; просто мы не наблюдали их в этот момент.

## Что осталось в массиве

| n | Угол 1 kHz | Угол 5 kHz, без полных оборотов | Оба значения |
|---|---|---|---|
| 0 | 0° | 0° | 1 |
| 1 | 60° | 300° = −60° | 0.5 |
| 2 | 120° | 240° = −120° | −0.5 |
| 3 | 180° | 180° | −1 |
| 4 | 240° | 120° | −0.5 |
| 5 | 300° | 60° | 0.5 |
| 6 | 0° | 0° | 1 |

В обоих случаях в памяти оказывается одна последовательность. По ней невозможно определить, какой из двух сигналов был на входе. Эта неоднозначность называется **aliasing**; 1 kHz называют низкочастотным alias — неотличимой по отсчётам частотой для сигнала 5 kHz при выбранной $F_s$.

Не сам аналоговый сигнал превратился в медленный: одинаковыми оказались его отсчёты и отсчёты медленного сигнала.

## Почему это работает для любого номера отсчёта

Здесь 5 kHz = Fs − 1 kHz. Для целого n:

$$
\cos\left(2\pi\frac{F_s-f}{F_s}n\right)
=\cos\left(2\pi n-2\pi\frac{f}{F_s}n\right)
=\cos\left(2\pi\frac{f}{F_s}n\right).
$$

Полные обороты $2\pi n$ ничего не меняют, а косинус одинаков для углов $+\theta$ и $-\theta$. Равенство справедливо для всех целых n. Поэтому запись в десять раз длиннее **не поможет**: новые отсчёты тоже совпадут.

Это равенство относится к нашим косинусам с нулевой фазой. При отражении частоты с произвольной начальной фазой у эквивалентного косинуса меняется знак фазы. Произвольные два сигнала с частотами f и Fs−f не обязаны совпадать отсчёт в отсчёт.

## Вернёмся к 48 kS/s

Механизм тот же: 47 kHz = 48 kHz − 1 kHz. На каждом шаге получаем 352.5° против 7.5°. После отбрасывания полных оборотов это −7.5° против +7.5° — одинаковая горизонтальная координата.

Для наших косинусов частоты можно «отражать» в полосу от 0 до Fs/2:

| Входная частота | Alias при Fs = 48 kS/s |
|---|---|
| 5 kHz | 5 kHz |
| 20 kHz | 20 kHz |
| 28 kHz | 20 kHz |
| 47 kHz | 1 kHz |
| 49 kHz | 1 kHz |

## Лаба: проверяем совпадение отсчётов

[Скрипт эксперимента](/labs/01/02-aliasing.py) строит непрерывные опорные кривые и отсчёты для 1/5 kHz при Fs = 6 kS/s, затем проверяет пару 1/47 kHz при Fs = 48 kS/s.

```sh
uv run labs/01/02-aliasing.py --show
```

Ключевой фрагмент:

```python
fs = 6_000
n = np.arange(60)
t = n / fs
slow = np.cos(2 * np.pi * 1_000 * t)
fast = np.cos(2 * np.pi * 5_000 * t)
print(np.max(np.abs(slow - fast)))
```

Получится число около нуля: небольшой остаток связан с вычислениями float64. Попробуй увеличить число отсчётов, затем отдельно поменять Fs с 6000 на 8000. Предскажи, в каком опыте равенство сохранится. Сам скрипт сначала выполняет проверки исходных условий; собственные изменения удобно делать в приведённом фрагменте.

## Как не потерять нужную информацию

Если все частоты действительного сигнала лежат в полосе от 0 до $B$, для однозначного восстановления по идеальной полной последовательности отсчётов выбираем **$F_s>2B$**. Граница $F_s/2$ называется частотой Найквиста. Предположение о полосе существенно: в сигнале до дискретизации не должно быть неизвестных составляющих за её пределами.

Перед реальным аналого-цифровым преобразователем (ADC) ставят **аналоговый фильтр защиты от наложения частот**, или *anti-alias filter*: он ослабляет частоты, которые могли бы наложиться на полезную полосу. Из-за конечной крутизны фильтра нужен запас между полезной полосой и Fs/2.

Если 47 kHz уже записались как 1 kHz, цифровой фильтр после ADC не сможет отличить их от настоящего полезного тона 1 kHz. При цифровом уменьшении Fs фильтр тоже нужен до удаления отсчётов — это разберём в части о смене частоты дискретизации (multirate DSP).

## Проверь понимание

При **Fs = 8 kS/s** сравниваем косинусы **1 kHz и 7 kHz**, оба с нулевой начальной фазой.

1. Найди интервал времени $T_s=1/F_s$ между измерениями. Какой угол за это время проходит точка для сигнала 1 kHz? А для 7 kHz? Используй $\Delta\theta=360^\circ f/F_s$.
2. Сравни горизонтальные координаты двух точек в моменты $n=0,1,2$. Совпадают ли они?
3. Будут ли совпадать и последующие отсчёты? Объясни, почему увеличение длины записи при прежней $F_s$ не различит эти косинусы.

Сначала ответь по окружности, затем проверь в Python. После этого разберём, что происходит точно на Fs/2 и почему «два отсчёта на период» — опасное упрощение.
