## Два ограничения цифровой записи

До сих пор мы выбирали моменты измерения, а значения отсчётов считали идеальными числами. Реальный аналого-цифровой преобразователь, или ADC, ограничивает и точность по амплитуде:

1. **Дискретизация (sampling)** выбирает моменты времени $t_n=n/F_s$.
2. **Квантование (quantization)** заменяет измеренное значение одним из конечного набора уровней и выдаёт соответствующий цифровой код.

Разрядность — число битов в коде. Больше битов позволяет различать более близкие значения амплитуды, но не исправляет наложение частот из предыдущих уроков. Здесь будем менять разрядность при неизменной частоте дискретизации.

## Модель преобразователя с положительными и отрицательными уровнями

Будем измерять сигнал в условных единицах: нижней границе шкалы соответствует $-1$, верхней — $+1$. Для разрядности $N$ есть $L=2^N$ кодов. В выбранной модели шаг между уровнями равен

$$
\Delta=\frac{2}{2^N}.
$$

При $N=3$ получаем восемь кодов со знаком и шаг $0.25$:

| Код $k$ | Представляемое значение $k\Delta$ |
|---:|---:|
| −4 | −1.00 |
| −3 | −0.75 |
| −2 | −0.50 |
| −1 | −0.25 |
| 0 | 0.00 |
| 1 | 0.25 |
| 2 | 0.50 |
| 3 | 0.75 |

Уровня $+1$ в этой модели нет. Так устроен выбранный нами диапазон целых чисел со знаком: от $-4$ до $+3$. Это соглашение соответствует дополнительному коду (*two’s complement*), который подробнее разберём при переходе к fixed-point. У конкретного ADC формат кодов может быть другим.

## От значения к коду и обратно

Для каждого входного значения $x[n]$ выполняем три действия:

1. Делим на шаг $\Delta$.
2. Округляем до ближайшего целого.
3. Если результат выходит за диапазон кодов, заменяем его ближайшим допустимым пределом.

В виде формулы:

$$
k[n]=\operatorname{clip}\left(\operatorname{round}\frac{x[n]}{\Delta},
-2^{N-1},\;2^{N-1}-1\right).
$$

Здесь `round` означает округление, а `clip` — ограничение диапазона. В скрипте используется `np.rint`: значение ровно посередине между целыми округляется к ближайшему чётному целому.

Чтобы показать на графике значение, соответствующее коду, умножаем его на шаг:

$$
x_q[n]=k[n]\Delta.
$$

Например, при трёх битах для входа $0.62$ получаем $0.62/0.25=2.48$. После округления код равен $2$, представляемое значение — $0.50$. Вход $0.74$ даёт код $3$ и значение $0.75$.

## Что хранится в цифровом сигнале

**ADC выдаёт коды.** В нашем примере в последовательности кодов будет целое число `2`. Его смысл в выбранной шкале — значение `0.50`.

В Python можно работать с обоими представлениями:

```python
codes = np.array([2, 3, -2])  # целые коды
step = 0.25
values = codes * step        # [0.50, 0.75, -0.50]
```

Массив `values` удобен для графиков и дальнейших вычислений. Перевод в числа с плавающей точкой не возвращает потерянную точность: исходные `0.62` и `0.50` могли дать один и тот же код. Для перевода нормированных значений в вольты нужна ещё шкала входного диапазона устройства.

## Ошибка квантования и ограничение диапазона

Определим ошибку как разность представляемого и исходного значения:

$$
e[n]=x_q[n]-x[n].
$$

Если округлённый код помещается в допустимый диапазон, то

$$
|e[n]|\le\frac{\Delta}{2}.
$$

Если код пришлось ограничить, эта гарантия пропадает. Например, для входа $0.90$ округление даёт код $4$, но максимальный допустимый код — $3$. Получаем значение $0.75$ и ошибку $-0.15$, по модулю больше половины шага $0.125$. Для входа $1.20$ ошибка будет ещё больше.

Такое ограничение называют **clipping**, или обрезанием сигнала по уровню. В нашей асимметричной модели оно может начаться ещё до $+1$: ориентируемся на допустимые коды, а не только на номинальные границы шкалы.

Ошибка квантования не всегда похожа на случайный шум. Для периодического сигнала она тоже может быть периодической. Её спектр рассмотрим после знакомства с DFT.

[Скрипт](/labs/01/04-quantization.py) сравнивает модели с разрядностью 3 и 8 бит:

```sh
uv run labs/01/04-quantization.py --show
```

![Квантование с разрядностью 3 и 8 бит](/labs/01/outputs/04-quantization/quantization.png)

Серая линия — исходный косинус, синие точки — идеальные отсчёты, оранжевые точки — значения, соответствующие кодам. Ступени соединяют оранжевые точки для наглядности; в массиве хранятся отдельные отсчёты. Нижняя панель показывает ошибку. Скрипт также печатает отдельно коды и соответствующие им значения.

Сначала сравни несколько разрядностей, затем увеличь амплитуду:

```sh
uv run labs/01/04-quantization.py --bits 2 3 4 8 --samples 48 --show
uv run labs/01/04-quantization.py --bits 3 --amplitude 1.2 --show --output-dir /tmp/dsp-clipping
```

Во втором опыте вершины упираются в предельные коды. Увеличение числа битов уменьшает шаг, но не расширяет выбранную входную шкалу.

## Что даёт дополнительный бит

Каждый дополнительный бит удваивает число уровней и уменьшает шаг вдвое. При округлении без ограничения кодов вдвое уменьшается и верхняя граница ошибки.

В реальном ADC точность также ограничивают собственный шум и нелинейность. Поэтому заявленная разрядность и фактическая точность могут различаться. Количественные оценки шума и эффективной разрядности оставим для соответствующей части курса.
