## Что мы уже увидели

При Fs = 48 kS/s и f = 24 kHz за каждый интервал между измерениями точка поворачивается ровно на 180°. Для косинуса с амплитудой 1:

| Начальная фаза | Первые четыре отсчёта |
|---|---|
| 0° | 1, −1, 1, −1 |
| 60° | 0.5, −0.5, 0.5, −0.5 |
| 90° | 0, 0, 0, 0 |

Физическая амплитуда во всех трёх строках одинаковая. Разница в том, куда попали моменты измерения. При фазе 90° сигнал достигает своих максимумов между отсчётами, а ADC каждый раз видит ноль.

В NumPy задаём фазу в радианах: `np.pi / 2` или `np.deg2rad(90)`. Число `90` означает 90 радиан и даёт совсем другой результат. Небольшой остаток около математического нуля в float64 — вычислительное округление.

## Одна формула объясняет все три случая

На границе f = Fs/2:

$$
x[n]=A\cos(\pi n+\phi).
$$

Раскроем косинус суммы:

$$
x[n]=A\bigl(\cos(\pi n)\cos\phi-\sin(\pi n)\sin\phi\bigr).
$$

Для целого n всегда $\sin(\pi n)=0$, а $\cos(\pi n)=(-1)^n$. Поэтому:

$$
\boxed{x[n]=\underbrace{A\cos\phi}_{C}\,(-1)^n.}
$$

Вся запись имеет вид **C, −C, C, −C, …**. Она сохраняет лишь одно число C — произведение амплитуды на косинус фазы. Отдельно A и φ восстановить из такой записи нельзя без дополнительной информации.

Это не случайная ошибка ADC: даже идеальные отсчёты содержат недостаточно информации.

## Неоднозначность есть и без нулей

Сравним два сигнала на Fs/2:

- A = 1, φ = 60° → C = 1 · 0.5 = 0.5;
- A = 0.5, φ = 0° → C = 0.5 · 1 = 0.5.

Оба дают **0.5, −0.5, 0.5, −0.5, …**. По массиву нельзя понять, какая амплитуда была на входе. А C = 0 может соответствовать как отсутствию сигнала, так и ненулевому косинусу с фазой 90°.

На окружности мы всё время видим только две противоположные точки. Увеличение длительности записи не добавляет новых положений.

## Лаба: сравниваем фазы и частоты

[Скрипт](/labs/01/03-nyquist.py) строит отсчёты для фаз 0°, 60° и 90° и проверяет пример с двумя разными амплитудами.

```sh
uv run labs/01/03-nyquist.py --show
```

![Три фазы на границе Найквиста](/labs/01/outputs/03-nyquist/nyquist-phases.png)

Теперь опустим частоту до 23 kHz, сохранив Fs = 48 kS/s:

```sh
uv run labs/01/03-nyquist.py --f 23000 --reference --show --output-dir /tmp/dsp-below-nyquist
```

Шаг угла станет **172.5°**, а не 180°. Точки перестанут чередоваться только между двумя положениями. В частности, при начальной фазе 90° отсчёты уже не будут все нулевыми. Флаг `--reference` добавляет исходный косинус, вычисленный на частой сетке времени. Чтобы рассмотреть несколько отдельных периодов, добавь `--samples 16`.

На длинной записи точки могут образовать рисунок, похожий на медленно меняющуюся огибающую. Амплитуда исходной синусоиды при этом постоянна: меняется положение моментов измерений относительно её максимумов. По внешнему виду редких точек нельзя заключить, что восстановление невозможно.

Можно сравнить и третий случай: f = 24 kHz при повышении Fs до 96 kS/s.

```sh
uv run labs/01/03-nyquist.py --fs 96000 --show --output-dir /tmp/dsp-higher-sample-rate
```

Получится четыре отсчёта на период и шаг 90°. Даже при начальной фазе 90° теперь наблюдаем 0, −1, 0, +1, …

## Что означает условие Найквиста

Для действительного сигнала, все частоты которого находятся в полосе от 0 до $B$, используем условие:

$$
F_s > 2B.
$$

**Строго больше** защищает от нашего примера с синусоидой прямо на границе. Мы предполагаем, что входной сигнал ограничен этой полосой: сама по себе высокая Fs не устраняет влияние любых неизвестных внеполосных сигналов.

В идеальной модели сигнал с ограниченным спектром восстанавливается по полной последовательности отсчётов. Это относится и к синусоиде 23 kHz при $F_s=48$ kS/s: близость к границе сама по себе не уничтожает информацию. В лабе запись конечна, а в устройстве измерения содержат шум — это дополнительные ограничения. Прямые линии между соседними точками не выполняют идеальное восстановление.

## Почему в устройстве закладывают запас

Перед ADC нужен аналоговый фильтр защиты от наложения частот. Реальный фильтр не может пропускать всё до $B$ и мгновенно подавлять всё сразу после $B$: между полосой пропускания и полосой подавления есть **переходная полоса** (*transition band*). Частотный план должен оставить место для спада фильтра и обеспечить достаточное подавление сигналов, которые могут наложиться на полезную полосу.

Поэтому «нам нужен сигнал до 20 kHz — значит, Fs = 40 kS/s» не подходит. Fs = 48 kS/s даёт границу 24 kHz и некоторый запас, но достаточность конкретного фильтра ещё нужно проверить. Единого обязательного коэффициента запаса для всех систем нет.

## Проверь понимание

При Fs = 48 kS/s и f = 24 kHz записали последовательность **0.5, −0.5, 0.5, −0.5, …**.

Можно ли по ней утверждать, что амплитуда исходной синусоиды была 0.5? Назови два варианта амплитуды и фазы, которые подходят к этой записи.

Второй опыт: уменьшаем частоту сигнала до 23 kHz при той же $F_s$. Как изменится шаг угла между отсчётами? Будут ли отсчёты по-прежнему описываться последовательностью $C,-C,C,-C,\ldots$?
