# Журнал обучения

Здесь появятся заметки по мере прохождения. Критерии освоения отмечаем в README соответствующей части; сейчас все они открыты.

Для каждой записи сохраняем:

- дату и ссылку на урок;
- прогноз до эксперимента и наблюдаемый результат;
- что стало понятно и какие вопросы остались;
- параметры, путь к эксперименту и интересным графикам;
- следующий небольшой шаг.

Можно добавлять файлы `YYYY-MM-DD-topic.md`. Архитектурные решения итогового проекта записываем с причиной выбора, альтернативами и измерением, на котором основан вывод. Для QMX/uSDX обязательно указываем версию устройства/firmware и первичный источник.
