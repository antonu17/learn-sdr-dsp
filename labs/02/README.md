# Лаба 02: комплексные числа и I/Q

## Комплексный вектор, координаты, модуль и фаза

Скрипт показывает один комплексный тон на плоскости I/Q и на графиках координат, модуля и развёрнутой фазы. Развёрнутая фаза сохраняет накопленные обороты вместо скачка угла на границе ±π.

```sh
uv run labs/02/01-complex-iq.py --show
uv run labs/02/01-complex-iq.py --index 12 --phase-deg 45 --show --output-dir /tmp/dsp-iq
```

`--index` выбирает подсвеченный отсчёт, `--phase-deg` задаёт начальную фазу в градусах. Интерактивный Python после выполнения:

```sh
PYTHONINSPECT=1 uv run labs/02/01-complex-iq.py
```

Доступны массивы `z`, `i`, `q`, `theta`. Например, `np.abs(z[8])` даёт модуль, `np.rad2deg(np.angle(z[8]))` — угол в градусах.

## Положительная и отрицательная частоты

Сравниваем встречные вращения: действительные части совпадают, мнимые меняют знак. Накопленная фаза одного сигнала растёт, другого убывает.

```sh
uv run labs/02/02-positive-negative-frequency.py --show
uv run labs/02/02-positive-negative-frequency.py --f 2000 --show --output-dir /tmp/dsp-negative-frequency
```

Во втором опыте при частоте дискретизации 8 kS/s шаг угла равен 90° вместо 45°.

## Косинус из двух вращений

Складываем сопряжённые вращения, наблюдаем компенсацию Q и сравниваем сумму с исходным косинусом:

```sh
uv run labs/02/03-real-cosine-rotations.py --show
uv run labs/02/03-real-cosine-rotations.py --amplitude 2 --phase-deg 30 --show --output-dir /tmp/dsp-cosine-pair
```

Во втором опыте амплитуда косинуса равна 2, начальная фаза — 30°. Каждое вращение в его разложении имеет амплитуду 1.
