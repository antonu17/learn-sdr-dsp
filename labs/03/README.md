# Лаба 03: Fourier, DFT и FFT

## Проверка частот и спектр суммы косинусов

Верхний ряд рисунка показывает комплексный тон 1 kHz и суммы результатов его умножения на два опорных сигнала. Нижний ряд — два действительных косинуса 1 и 2 kHz с амплитудами 1 и 0.5, их сумму и её двусторонний спектр.

```sh
uv run labs/03/01-frequency-probe.py --show
```

Пунктирные кривые внизу слева — исходные косинусы, чёрная — сумма, синие точки — её отсчёты. В DFT поступают только отсчёты. По вертикали спектра отложено |X|/N, поэтому пики на ±1 kHz имеют высоту 0.5, на ±2 kHz — 0.25.

При N = 32 и Fs = 8 kS/s шаг сетки DFT равен 250 Hz. Другой опыт с частотами на этой сетке:

```sh
uv run labs/03/01-frequency-probe.py --tone1 750 --tone2 1750 --wrong-probe 1250 --show --output-dir /tmp/dsp-frequency-probe
```

`--wrong-probe` задаёт проверяемую частоту; опорное вращение в вычислении имеет противоположный знак. Скрипт считает DFT напрямую и сравнивает результат с `np.fft.fft()`.
