- [Лаба 02: комплексные числа и I/Q](02/README.md)
- [Лаба 03: Fourier, DFT и FFT](03/README.md)

Основные инструменты — Python, NumPy, SciPy и Matplotlib. Каждый исполняемый скрипт содержит зависимости в блоке `# /// script` (PEP 723). Запускаем из каталога проекта через `uv run labs/<часть>/<скрипт>.py`. Для открытия графиков добавляем `--show`; без этого флага скрипт сохраняет изображения и завершает работу.

Базовые модели используют float64 для действительных чисел и complex128 для комплексных. Ограниченную точность моделируем явно. Файлы Jupyter допустимы для исследований, но воспроизводимый опыт сохраняем в небольшом скрипте.

Результаты находятся в `labs/<часть>/outputs/<опыт>/`. Скрипты с параметром `--output-dir` позволяют сохранить отдельный вариант в другой каталог. На сайте код и графики берутся из автоматически создаваемой копии `public/labs/`; её вручную не редактируем.

Для каждого опыта записываем параметры, частоту дискретизации, единицы и ожидаемый результат. Если есть случайные данные, сохраняем seed генератора. У спектров указываем нормировку, окно и шкалу. При сравнении трактов учитываем задержку и переходный процесс.

Самостоятельные реализации сравниваем с NumPy/SciPy, обработку блоками — с целым массивом, целочисленную модель — с выбранными правилами разрядности и округления. Допуск проверки должен соответствовать измеряемой величине. Результат лабы — график, численная проверка и объяснение наблюдаемого эффекта.
