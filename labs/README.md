# Python-лаборатория: соглашения

Это место для будущих экспериментов. Код и зависимости сейчас не устанавливаются.

Основной стек: Python, NumPy, SciPy / scipy.signal, Matplotlib. Для complex data используем complex128, для real data — float64 до явного перехода к ограниченной точности. Notebook/Jupyter допустим для исследования; небольшой `.py` script удобен для повторяемого запуска. Версии окружения зафиксируем при первом исполняемом уроке.

Будущие материалы группируем по номеру части и урока, например `labs/01/01-sine-sampling.py` или `.ipynb`. Не поддерживаем две копии одного эксперимента без необходимости. Каждый урок ссылается на свой эксперимент, эксперимент указывает соответствующий урок.

Графики и отчёты сохраняем в `labs/<часть>/outputs/<урок>/`, если их нужно хранить. Общие функции выделяем в отдельный модуль только после появления реального повторного использования. Структуру кода трансивера определим в части 17 на основе интерфейсов готовых блоков.

Для воспроизводимости сохраняем параметры, seed, единицы, Fs и dtype. У спектров указываем окно, нормировку и шкалу; у сравнений компенсируем известную задержку и учитываем переходные процессы. Простые реализации сверяем с NumPy/SciPy, streaming — с обработкой целого массива, fixed-point/HDL — с integer golden reference. Допуски выбираем под измеряемую величину.

Минимальный набор представлений: waveform и spectrum после части 03; далее PSD, I/Q, phase, impulse response, constellation по смыслу опыта. Результат урока — не только график, но и короткое объяснение наблюдаемого эффекта.
