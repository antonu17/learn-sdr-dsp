## Запуск

Зависимости объявлены прямо в начале скрипта в блоке `# /// script` (PEP 723). `uv` подготовит окружение при запуске:

```sh
cd ~/projects/learn-dsp
uv run labs/01/01-sine-sampling.py
```

Запуск с окнами графиков:

```sh
uv run labs/01/01-sine-sampling.py --show
```

Для сохранения в другой каталог используй `--output-dir <путь>`. Без `--show` используется backend Agg, которому не требуется графическое окно.

Фактические версии NumPy/Matplotlib записываются в отчёт при каждом запуске. Прямые зависимости закреплены в метаданных скрипта. `requirements-tested.txt` сохраняет список пакетов первоначального проверенного запуска как справочный снимок. SciPy понадобится в следующих уроках; этот эксперимент использует только NumPy и Matplotlib.

Результаты находятся в `outputs/01-sine-sampling/`: `01-sampling-phase.png`, `02-aliasing.png`, `measurements.txt`. Скрипт автоматически проверяет совпадение alias-пар с абсолютным допуском 10⁻¹¹ для исходных параметров; это допуск вычислений float64, а не модель погрешности ADC.

Варьируй параметры в начале скрипта по одному. Отдельный опыт aliasing рассчитан на Fs = 48 kS/s; для смены Fs нужно пересчитать и соответствующие пары частот.

## Как посчитать конкретный отсчёт

[Скрипт sample-value.py](sample-value.py) выводит каждый шаг: номер n → время n/Fs → угол в радианах и градусах → A·cos(угол). Нумерация начинается с нуля; фаза задаётся в радианах.

Первые четыре отсчёта при Fs = 48 kS/s, f = 24 kHz, A = 1, phi = 0:

```sh
uv run labs/01/sample-value.py
```

Другой сигнал и конкретные номера отсчётов:

```sh
uv run labs/01/sample-value.py --fs 48000 --f 12000 --n 0 1 2 3 17
uv run labs/01/sample-value.py --f 2000 --amplitude 0.5 --phase 1.5707963267948966 --n 0 1
```

`--phase 1.5707963267948966` соответствует π/2. Полный список параметров: `uv run labs/01/sample-value.py --help`. Малый остаток около 1e-16 вместо математического нуля связан с точностью float64.

## Граница Найквиста

```sh
uv run labs/01/03-nyquist.py --show
uv run labs/01/03-nyquist.py --f 23000 --show --output-dir /tmp/dsp-below-nyquist
uv run labs/01/03-nyquist.py --fs 96000 --show --output-dir /tmp/dsp-higher-sample-rate
```

Сравнивает фазы 0°, 60° и 90°. Частоты задаются в Hz и samples/s; количество отсчётов — через `--samples`. Проверяет, что на Fs/2 разные амплитуды и фазы могут давать одинаковые отсчёты.

### Показать исходную синусоиду

Флаг `--reference` добавляет оранжевую опорную кривую исходного косинуса на плотной временной сетке; синие точки остаются отсчётами. Это вычисление известного входного сигнала по формуле, а не интерполяция отсчётов. Без флага сохраняется прежнее отображение.

```sh
uv run labs/01/03-nyquist.py --f 23000 --fs 48000 --reference --show --output-dir /tmp/dsp-reference
```

Для рассмотрения отдельных колебаний добавь `--samples 16`. Возле Fs/2 значения отсчётов могут образовывать видимую медленную «огибающую», хотя амплитуда исходного косинуса постоянна. На коротком интервале видно, как моменты измерений постепенно смещаются относительно максимумов и минимумов синусоиды.

## Квантование

```sh

```

Сравнивает идеальные отсчёты с кодами ADC с разрядностью 3 и 8 бит и уровнями обоих знаков. Через `--bits`, `--amplitude`, `--phase`, `--f`, `--fs` и `--samples` можно менять параметры. Опыт с обрезанием вершин:

uv run labs/01/04-quantization.py --bits 3 --amplitude 1.2 --show --output-dir /tmp/dsp-clipping
