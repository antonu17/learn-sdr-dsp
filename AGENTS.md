# Работа с курсом

- Основной формат новых уроков — MDX в `src/content/course/`; оригиналы в `curriculum/` сохранены как снимок до перехода на Astro.
- Объяснения давай последовательно: интуиция → математика → эксперимент → самопроверка. Не объявляй отдельно язык материалов.
- Сохраняй Python как основную лабу. Все исполняемые Python-скрипты должны иметь PEP 723 inline dependencies и запускаться через `uv run`.
- Используй `$...$` и `$$` для формул. Интерактивные вставки — небольшие Astro-компоненты; не заменяй ими воспроизводимые Python-эксперименты.
- Будущие части курса остаются roadmap до прохождения. Не выдавай планы за готовые уроки и не отмечай освоение без ответа ученика.
- После изменений сайта выполняй `npm run build`; при изменении взаимодействий проверяй их в браузере. `public/labs/` генерируется из `labs/`.

- Раздел с экспериментами называй «Лаба». Объясняй термины при первом появлении; предпочитай обычные слова смеси вроде «frequency каждого sample». В самопроверке явно задавай исходные данные и называй искомую величину.
